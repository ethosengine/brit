# Public compatibility

The command matrix and generated shortcomings describe observed and deferred
behavior. The capability map routes work to existing crates; it is not a second
status register. Preserve intentional differences and unavailable evidence.
Git v2.54.0 under vendor/git is the reference source. A system Git executable
must have its version recorded before its behavior can be cited as that oracle.


The pinned reference in `git-reference.json` selects immutable Git source objects.
`git-census.json` and `GIT-CENSUS.md` are generated by `etc/parity/enumerate.sh`;
never hand-edit their counts or nodes. `.epr-meta/git-boundaries.json` owns explicit
boundary decisions. Missing code does not imply exclusion. Every terminated edge
retains its Git node, owning boundary, reason, alternative and reconsideration
condition. The comparison distinguishes proposed from adopted decisions. Neither
parser reflection nor historical matrix prose establishes behavior.

Atomic walks derive from the same pinned census. Preserve shared definition identity
separately from command-context occurrences, and option-name atoms separately from
capability groups. Section edges and nested-verb candidates are documentation
structure, not executable scoping. Zero extractable names cannot count as matched;
conditional applicability remains unresolved. Command boundary decisions inherit to
descendant groups without removing their contribution to the reference denominator.

The native interpretation is declared in `compatibility-measure-lens.md`: Middot
observe the reference and implementation, while a Mishpat lens consumes observations
to inform policy. Preserve those recall tags and the measurement/authority boundary.
A discoverable design artifact does not imply runtime measure registration, lens
ratification or independently witnessed evidence.

Legacy parity receipts reconcile through `etc/parity/reconcile.py`. Match candidate
atoms to the assertion actually executed; preserve exit-only, normalized-output,
skipped, deferred, unexecuted and ambiguous evidence. Native observations explicitly
consume `.epr-meta/measures.yaml` via the existing EPR interface and must be
re-derived against current sources before recording. Measurement production can
succeed with red assertions; CI success for that step never implies Git parity.
